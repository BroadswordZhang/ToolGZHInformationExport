# 12个免费深度学习算法模型库和资源库

![]()

点击下方公众号关注，一起进步，持续传达瓜货

![]()

大家好，我是张大刀。

在日常算法调研时，经常是想快速的出个算法的demo,或者放在下游任务中，用于算法的部署。于是收集了很多可以在算法调研阶段日常使用的工具，分享给大家，希望对大家的深度学习和日常工作有帮助。

**1. Papers With Code**

Papers with code 是由Meta AI Research 团队主导的一个开放资源的社区，汇集了深度学习论文、数据集、算法代码、模型以及评估表。

![]()

主页上有最新的趋势报告、高star的论文和代码。针对每一个数据集，下面有很多个人的类似于打榜的算法的实现。

![]()

如上图，在ImageNet数据集下面，有不同算法的实现，并链接对应的代码、论文以及评估结果，方便复现。这里一般在算法调研或者跟进最新的算法研究时使用，可以时常关注。

*链接：https://paperswithcode.com/*

**2. OpenModelZoo**

OpenModelZoo是预训练的深度学习模型和展示的存储库，开发人员可以通过它来加速开发和生产部署的过程。

这里的资源模型可以分成两类：英特尔的预训练模型以及公共的预训练模型。存储库中大概有200多个模型，涵盖图像检测、位置识别、文本、语音等。用户还可以使用一些演示demo,以及对其他框架模型的准确性评价.

![]()

![]()

该存储库主要为了适配英特尔针对openvino的推理框架，如果你是在用openvino做部署，这个可以在这个网站上找到很多学习资源，特别是sample/demo中的实例。

*链接：https://github.com/openvinotoolkit/open\_model\_zoo*

**3. Jetson Zoo**

Jetson Zoo 同OpenModelZoo一样，是一个开源目录，其中包含在 NVIDIA Jetson 上安装附加包和框架的指南。它还包括用于在 Jetson 上进行推理的 DDN 模型，并支持 TensorRT。

![]()

Model Zoo 里包括分类、对象检测、分割和姿势估计模型、代码示例以及原始源码的链接。

![]()

此外，NVIDIA 还提供为 Jetson 开发人员套件创建的社区项目。这些项目包含代码、视频和说明，如果你的算法最后要部署在Jetson 上，可以在上面找到自己要的算法，再去优化，部署时会避免很多坑。。

*链接：https://developer.nvidia.com/embedded/community/jetson-projects*

**4. ModelZOO**

Model Zoo中包含了各种框架和领域的预训练深度学习模型，其中包括 TensorFlow、PyTorch、Keras、Caffe 等框架。这些模型现在是 Google 的机器学习研究员的 Jing Yu Koh 构建，这里的模型不多，各个领域均有涉及，重点在于其中的每个模型或者库都有实现的细节，方便其他人基于此做算法的二次开发或者优化。

![]()

![]()

*链接：https://modelzoo.co/*

**5. Tensorflow Hub**

TensorFlow 是一个流行的深度神经网络训练和推理框架。借助 TensorFlow Hub，可以直接下载预训练模型进行机器学习的推理或者迁移学习。

![]()

*链接：https://www.tensorflow.org/hub/overview*

**6. Tensorflow Model Garden**

Model Garden 由也是TensorFlow 团队维护，包含各种不同的 SOTA 模型实现、示例实现和建模最佳实践。  
该存储库具有四个主要目录：  
1. 是使用最新 TensorFlow 2 API 的 SOTA 模型实现集合。  
2. Research包含处于研究阶段的 TensorFlow 1 或 2 中的模型实现。  
3. 社区包括一个由 TensorFlow 2 驱动的 GitHub 存储库的精选列表。  
4. Orbit是一个库，使用户能够在 TensorFlow 2 中编写自定义的训练循环代码。

![]()

*链接：https://github.com/tensorflow/models/tree/master/official*

**7. MediaPipe Models**

MediaPipe是一个开源跨平台，为直播和流媒体提供可定制的机器学习解决方案。一些解决方案包括实时运动跟踪、面部网格、KNIFT 和自拍分割。虽然仍处于 alpha 阶段，但 Google Nest 和 Ariel AI（被 Snap 收购）等产品已经在使用 MediaPipe 解决方案。

![]()

*链接：https://google.github.io/mediapipe/*

**8. Awesome Tensorflow Lite**

TensorFlow Lite 专为在计算能力有限的设备（例如手机和嵌入式设备）上运行推理而构建。

![]()

*链接：https://github.com/margaretmz/awesome-tensorflow-lite*

****9********. Awesome CoreML Models****

Core ML 是 Apple 发布的一个框架，使开发人员能够将机器学习集成到应用程序中。借助Awesome CoreML Models，可以获得 Core ML (iOS 11+) 中最大的模型列表，可以使用这些模型在 iOS、macOS、tvOS 和 watchOS 上进行试验和实施。如果你的算法要部署在苹果产品上，可以选用上面的模型来避坑。

![]()

![]()

*链接：https://github.com/likedan/Awesome-CoreML-Models*

**10. Pinto Model Zoo**

Pinto Model Zoo 由 Katsuya Hyodo 创建，是一个共享由 TensorFlow 或 Keras 生成的训练模型的调优结果的存储库。迄今为止，它包含超过 260 个优化模型。使用的训练后量化技术包括权重量化、整数量化、全整数量化、Float16 量化）和量化感知训练。可以用于快速部署。

![]()

![]()

*链接：https://github.com/PINTO0309/PINTO\_model\_zoo*

**11. ONNX Model Zoo**

开放式神经网络交换 (ONNX) 是一种用于表示机器学习模型的开源格式。借助 ONNX Model Zoo，可以在 ONNX 中探索和使用社区贡献的预训练 SOTA 模型,有各种视觉、语言和其他有趣任务的模型。

![]()

![]()

*链接：https://github.com/onnx/models*

**12. Deci's Hardware Aware Model**

Deci 是一个端到端的深度学习开发平台，主要让算法人员从构建、优化模型并将其部署到任何环境和硬件。它包括一个Model Zoo，其中包含用于所有主要任务的基于 PyTorch 的计算机视觉模型。与其他Model Zoo不同，Deci Zoo中的模型针对各种硬件类型进行了预训练和优化（编译和量化）。  
除了显示每个模型的准确性之外，还可以轻松选择目标推理硬件并查看模型的运行时性能结果，例如各种硬件的吞吐量、延迟、模型大小和内存占用。

唯一的遗憾是，需要注册，有的模块需要购买。

![]()

*链接：https://deci.ai/resources/videos/tutorial-infery/*
