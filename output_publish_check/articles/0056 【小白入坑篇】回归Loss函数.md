# 【小白入坑篇】回归Loss函数

卷积神经网络（ConvNets或CNNs）作为一类神经网络，托起深度学习的发展，本文主要介绍卷积神经网络的另外一个操作——loss，其原理，针对不同的场景的loss设计也不相同，这里主要为loss系列的回归loss函数。

> **前言**

今天开始我们**回归损失loss**的讲解，错过分类loss的请点击[这里](http://mp.weixin.qq.com/s?__biz=MzU3ODk2Njc5Mg==&mid=2247487096&idx=1&sn=572f584f45aa5e4493e738d105ae11ce&chksm=fd6c0a1fca1b8309b3bc515ab35cf8954346c06622f13c01a3585e6e3df10927652c65e21ae2&scene=21#wechat_redirect)。

回归损失函数的一般场景在目标检测中框的回归。这里引申下，为啥分类要交叉熵损失，而框以及关键点会用回归损失呢？主要原因在数据分布上，一般默认分类接近**多项式分布**，而回归任务默认数据接近**高斯分布**，那为何数据分布会影响到loss的选取呢，这里的内容涉及统计学等，欢迎大家讨论，有机会加一篇文章写下个人理解【1】【2】。所以，不是分类任务就会一定会用到交叉熵损失，回归任务，就一定会用到均方差损失等这样，比如有大佬在回归任务中使用交叉熵损失【3】。

这样看以场景划分loss好像不太科学![]()，为了方便自己梳理和大家理解，先这样划分吧。

以下是**文章思路**：在目标检测中涉及框的回归，从MSE loss →Smooth L1 Loss→IOU loss → Giou Loss → DIou Loss →CIou Loss→EIou Loss →focal EIou Loss 。

> 1
>
> **MSE loss**

**MSE loss函数**是最简单的回归损失函数，简称均方差函数,L2损失函数，还有个L1损失函数：

![]()

![]()

L1损失函数与L2损失函数最早被用于回归任务中：

![]()

两者各自有优缺点，L1损失最大的优点在于它的**鲁棒性**，它对于异常值特别是很大的异常值不敏感性小于L2loss,  从直观上说，因为L2范数将误差平方化（如果误差大于1，则误差会放大很多），模型的误差会比L1范数来得大，因此模型会对这个样本更加敏感，这就需要调整模型来最小化误差。如果这个样本是一个异常值，模型就需要调整以适应单个的异常值，这会牺牲许多其它正常的样本，因为这些正常样本的误差比这单个的异常值的误差小。L2损失的优点在于它的**光滑性**，它在0点上平滑过渡，梯度可导。

> 2
>
> **Smooth L1 Loss**

**smooth L1**说的是光滑之后的L1，结合了L1和L2 loss的优点，

smooth L1损失函数为：

![]()

相对于L2 loss,当预测值与目标值相差很大时, 梯度容易爆炸(*x-t*), smooth L1将梯度被替换成±1，这样就避免了梯度爆炸，提高算法的鲁棒性。在早期的目标检测算法如faster RCNN,SSD等中，bbox的回归均采用的是这个损失函数，但是它的缺点在于，考虑回归的精确性，没有考虑到框的回归场景，默认为回归的四个值是相互独立的，而实际上，如果(x,y)在右下角时，h和w只能取0。同时评价检测框的是IOU，IOU与smooth L1变化不匹配。

> 3
>
> **IOU loss**

基于smooth L1的缺点，**IOU loss**在2016年被提出来：【4】

![]()

![]()

IoU 计算让x，y，w，h 相互关联，同时具备了尺度不变性，其缺点在于：1、 当预测框和真实框不相交时，IoU=0时，不能反映预测框和真实框距离的远近，此时损失函数不可导，IoU Loss 无法优化两个框不相交的情况。同时，假设预测框和目标框的大小都确定，只要两个框的相交值是确定的，其IoU值是相同时，IoU值不能反映两个框的相对位置，基于Iou loss的缺点，后续各个Iou系列loss 思路均是增加**惩罚项**，使得loss更能表达框的实际状态。

>

GIoU loss 在Iou Loss的基础上增加了惩罚项，取值范围为 [-1, 1]，在两框重合时取最大值 1，在两框无限远时取最小值 -1；同时与 IoU 只关注重叠区域不同，GIoU 不仅关注重叠区域，还关注其他的非充和区域，能更好的反映两者的重合度。GIOU包含了IOU所有的优点，同时克服了IOU的不足，IOU是GIOU的下限，缺点在于：当目标框完全包裹预测狂的时候， IoU 和 GIoU 的值都一样，此时 GIoU 退化为 IoU，无法区分其相对位置关系。

>
> **focal EIou Loss**

还是EIou的延伸，首先作者基于[focal loss](http://mp.weixin.qq.com/s?__biz=MzU3ODk2Njc5Mg==&mid=2247487096&idx=1&sn=572f584f45aa5e4493e738d105ae11ce&chksm=fd6c0a1fca1b8309b3bc515ab35cf8954346c06622f13c01a3585e6e3df10927652c65e21ae2&scene=21#wechat_redirect)的二分类loss，提出focal L1 loss，作者的**设计思路**很有意思，先去设计反向传播的梯度，**基于梯度去设计损失函数**；

在此之前，作者先设计了提出了梯度需求：1、当回归的error是0的时候，此时的梯度也应当是 0，因为我们这时不再需要对参数进行调整；2、在错误率小的地方，梯度的值也应当小，反之在错误率大的地方，梯度也应当大，因为这时候我们需要对错误率小的情况进行微调，而错误率大的地方进行大刀阔斧的调整；3、应该有一个参数可以抑制低质量样本对损失值的影响；4、梯度值的范围应该在一定的范围内，例如(0,1]，不然可能会造成梯度的剧烈波动。于是作者提出了这样的梯度，

> 结语

至此，回归算法已经从早年的均方差，到2015年凯明大神提出fasterrcnn带火smoth L1，到16年后IOU系列的快速迭代，卷出天际。目标检测bbox回归算法告一段落，以上算法没有谁好谁差之分，在不同的数据集上表现的也不一样，在实际项目中尽可能多的尝试在自己的数据集上，**有效果才是王道**。
