# [算法开发实用技巧案例一]：合理使用动态库

本系列主要分享在实际项目过程中，一些实用的小技巧，能快速提升算法的工作效率。

> **前言**

在做项目过程中会有一些功能需要反复的运用到，其中有的功能比较耗时间并且对内存资源的消耗也是比较大的。在本文中将分享如何通过**c++的动态库**节约开发时间成本以及项目实施过程中的硬件资源成本，提高工作效率降低资源的消耗。

              

**01****案例分析**

在这里我以自己在项目的经常用到的功能：**在图片中写字符（汉字）**。对于图像和视频流的读取以及对图像数据的各种尺寸和色彩空间的变换使用的是OpenCV进行实现的，但是在OpenCV往图像中添加中文字符的时候却是不支持的，在这里采用的方案是转为PIL型数据进行添加中文字符，待到添加完成后再转回OpenCV格式的数据。在这个过程中我们不仅消耗了大量的时间同时也增加了封装后模块化的内存大小。

为了解决上述的问题，对各种解决方案调研后得到可通过使用**C++生成动态链接库（DLL/SO）**实现在OpenCV中添加中英文。这里我们仅需要将**图像数据转为Char格式传染动态链接库文件中，使用该库内部二进制方式实现在图像中添加中文后返回Char格式数据**即可。采用动态链接库方案相较于转为PIL库方案对运算效率有质的提高以及对程序运行时资源的消耗有较为明显的降低。

**02 效果****比对**

在这里我们在同一台PC端实现案例分析中的两种方案，在PC端使用的是WIN系统因此生成的动态链接库为DLL。为了比较数据这里采用同一图像数据并分别测试验证汉字（“德龙软件”）。由于单次的运算时间较快，这里采用的是运行10000（一万次的运行总时间）进行比对。    

|  |  |  |
| --- | --- | --- |
| 方案： | 图像大小： | 汉字耗时： |
| OpenCV+PIL | 640\*480\*3 | **16.31秒** |
| OpenCV+DLL | 640\*480\*3 | **1.35秒** |

从上述表格中可发现使用OpenCV+DLL【C++生成DLL】供调用方式相较于OpenCV+PIL方式在运行时间上缩短了91.72%的时间，这对日常项目中的模块运用是极其便利的。

**03 代码示例**

**方案一：Opencv + PIL**

```
import time  
import cv2  
import numpy  
from PIL import ImageDraw, ImageFont, Image  
  
  
def paint_chinese_opencv(im, chinese, pos, color):  
  
    img_PIL = Image.fromarray(cv2.cvtColor(im, cv2.COLOR_BGR2RGB))  
    font = ImageFont.truetype('msgothic.ttc', 80)  
    fillColor = color  # (255,0,0)  
    position = pos  # (100,100)  
    draw = ImageDraw.Draw(img_PIL)  
    draw.text(position, chinese, font=font, fill=fillColor)  
  
    img = cv2.cvtColor(numpy.asarray(img_PIL), cv2.COLOR_RGB2BGR)  
    return img  
  
  
if __name__ == '__main__':  
    img = cv2.imread('test.jpg')  
    chinese = "德龙软件"  
    pos = (100, 100)  
    color = (255, 0, 0)  
    t1 = time.time()  
    for i in range(10000):  
        chimg = paint_chinese_opencv(img, chinese, pos, color)  
    print(time.time() - t1)
```

**方案二：Opencv + DLL**

```
import ctypes  
import time  
  
import numpy as np  
import cv2  
from ctypes import *  
  
def Mat2Uchar(matImg):  
    Mat = np.asarray(matImg, dtype=np.uint8)  
    Uchar = Mat.ctypes.data_as(c_char_p)  
    return Uchar  
  
def Uchar2Mat(uchar):  
    length = len(uchar)  
    matImg = (c_uint8 * length).from_buffer_copy(uchar)  
    Mat = np.asarray(matImg)  
    return Mat  
  
# Load the DLL  
my_dll = ctypes.CDLL("dralChinese.dll")  
drawChinese_func = my_dll.drawChinese  
drawChinese_func.argtypes = [c_char_p, c_int, c_int, c_char_p, c_int, c_int, c_int, c_int, c_int, c_int]  # 定义输入值类型  
drawChinese_func.restype = ctypes.POINTER(ctypes.c_ubyte)  
  
img = cv2.imread("test.jpg")  
Uchar = Mat2Uchar(img)  
input_text = "德龙软件"  
input_text = input_text.encode('ANSI')  
  
t1 = time.time()  
for i in range(10000):  
    data_ptr = drawChinese_func(Uchar, img.shape[1], img.shape[0], input_text, 100, 100, 80, 0, 0, 255)  
    image_array = np.ctypeslib.as_array(data_ptr, shape=(img.shape[0], img.shape[1], 3))  
print(time.time() - t1)  
cv2.imwrite("test_ch.jpg", image_array)
```

**04 总结**

C++是一种静态类型、编译型语言，它在执行前就已经完成了大部分的性能优化，因此通常能提供较快的执行速度；而Python作为一种动态类型的解释型语言，其运行效率通常低于编译型语言。

1.**避免臃肿的代码模块，降低参数之间的耦合**。例如在编写一些应用程序的时候的头文件高达四五个并且还需要注意各变量名称是否相似，在实际应用中会带来一些不便。

2. **可重复利用，避免多个程序对同一依赖的反复打包，程序轻量化设计**。多个应用程序可能依赖于同一个动态链接库，这个库就可以以DLL的形式存在，被所有这些应用共享。

3**.按需加载**。当应用程序启动或运行时，如果需要调用某个功能且该功能是由DLL提供的，系统会动态地加载这个DLL文件到内存中。这意味着DLL文件并非一开始就全部加载，而是根据需要进行加载，从而优化了资源使用。

4.**执行效率高，运算速度快**。在开发效率上Pyhton相较于C++有着极大的优势，但是在执行效率中我们往往会因为Python中的一些操作导致执行效率影响最终结果，这时可使用C++进行改写助力Python的运算

5.**后期维护便捷**。通过提供共享代码和数据的功能，对复杂耗时的部分优化后可直接更新动态链接文件也使得程序升级更为简便，无需重新安装整个应用程序。

总结来说，无论是Windows系统中的DLL文件还是Linux系统中的SO文件，它们都是现代操作系统中不可或缺的组成部分，通过提供共享代码和数据的功能，大大优化了程序的性能和资源使用效率。了解它们的工作原理和正确管理方式对于维护系统稳定性和性能至关重要。
