**01 注意力机制**

首先我们先了解下注意力机制中的q,k,v三个值，这三个其实是来自于推荐算法中的。

![]()

如我们在淘宝上搜索“手机壳”这个商品，那个“手机壳”即为query，需要查询的商品，在点击搜索过后，后台会去查询相关度高的商品k，然后并将其召回出来，那这个相关性怎么定义的呢，他是根据你需要查询的商品和系统的商品标签进行匹配，根据相似度来召回，即q\*k。

第二步，在我们召回的商品中进行一个排序，把有价值的商品放在前面，比如根据销量、评价等因素即为value，我们把刚刚计算的相似度与商品的value相乘，即得到查询结果的总分，再根据这个总分来排序。

那在我们将上述的问题简化成下面的图：

![]()

q为需要查询的商品，c1,c2,c3为系统中的各个商品，会提供k1,k2,k3即商品名称，和对应的商品价值v1,v2,v3, 首先通过q与各个k之间计算相似度α，再通过相似度和商品的价值计算，得到系统中查询商品的分数，根据分数来排序，在系统上展示。这里q(query)为主动与其他token（c）计算相似度，k(key)为被用于去其他token计算相似程度的，value为当前token的重要程度值。

以上即为从商品推荐算法中引申出来的注意力机制的基本概念。注意力机制即关注最主要的东西，而尽量忽略次要的东西。

**02****self-attention 机制**

**一、基本原理**

而对于cv或者nlp中，通常给定的是一张图片或者一个句子，不存在外界给定的query去查询，同时我们想得到的是这张图片中，各个模块之间的相关性或者相似度，那怎么办呢，这样就可以自己产生对应的query,key和value, 如果想知道这个模块和其他模块之间的相关性，则可以通过计算这个query与其他模块的key来获得相似度，这也是self-attention中self要表达的意思，即对于一张图片，所有的query,key和value都是自己产生的，即输入的内部元素之间的发生的attention机制，即一种特殊情况下的注意力机制。

![]()

如在cv上，一张2\*2\*3的图片，通过裁剪成4个1\*1\*3的模块，每个模块fatten过后即为4个3长度的一维向量（为何要做这样的裁剪和fatten我们后面再讲），通过embedding(这里暂时先不展开讲embeding的具体操作，大家可以理解为一种对向量特征提取操作)后，获得4个3长度的token，而self-attention操作即每个token会产生对应的query, key和value值。

![]()

如果我们想知道a1与其他a2,a3,a4各个模块的相似度，则通过a1的query与其他模块的key相乘，如果想知道其他模块对a1模块的价值的话，则通过获得的相似度与各个模提供的信息量（即value）相乘，则得到其他模块对a1的价值，即对a1模块的影响。

下面我们来看下self-attention具体的计算步骤。首先self-attention的计算公式为：

![]()

里面涉及到Q，K以及V，相对于前面简单相乘得到的结果，这里增加了除以根号d\_k以及softmax的操作，这里的表示k的维度，原论文中解释到，当Q和K的维度比较大时，两者相点乘会得到一个很大的值，如果不除的话，这样softmax会将其拉到饱和区域中，其梯度比较小，很难迭代，在这些操作完再与V进行相乘。

## **二、  计算步骤**

1. 定义输入

根据上图，在前面一系列操作后，我们输入一个4\*3的token，pytorch代码如下：

```
import torch  
x =[  
[1,0,1],# a1  
[1,1,0],# a2  
[1,1,1],# a3  
[0,1,1]# a4  
]  
x = torch.tensor(x, dtype=torch.float32)
```

2.  初始化权重

四个token,我们需要基于token来提取对应的q,k,v，则每一个token需要和三个权重矩阵相乘得到三个新矩阵，即该token对应的query, key和value。因为token长度为3，而有四个token,则三个权重矩阵的维度可以设置为3x4，这里需要注意的是，因为后面K与Q之间需要点乘，所以两者的矩阵需要相同，即w\_query和w\_key是矩阵维度保持一致，维度需要设置成3x4，而V是与softmax后的标量相乘，则w\_value的维度可以不用前面保持一致，维度可以设置成3xn。

pytorch代码如下：

```
w_key = [  
  [1, 2, 3, 0],  
  [2, 3, 4, 1],  
  [2, 0, 1, 2]]  
w_query = [  
  [1, 3, 1, 0],  
  [1, 0, 3, 1],  
  [4, 5, 1, 3]]  
w_value = [  
  [0, 2, 1, 3],  
  [1, 1, 4, 2],  
  [2, 3, 6, 3]]  
w_key = torch.tensor(w_key, dtype=torch.float32)  
w_query = torch.tensor(w_query, dtype=torch.float32)  
w_value = torch.tensor(w_value, dtype=torch.float32)  
  
print("Weights for key: \n", w_key)  
print("Weights for query: \n", w_query)  
print("Weights for value: \n", w_value)
```

3.  计算Q,K和V

因每个token均共用一套权重矩阵，这样计算可以并行。并行方式即将a1,a2,a3,a4 concat起来后，得到一个4x3的矩阵，即我们的输入，再分别与w\_key、w\_query和w\_value相乘，得到对应的K,Q和V.

![]()

下图为具体每个token根据右侧的权重矩阵，得到的q,k和v:

![]()

计算代码如下：

```
querys = x @ w_query  
keys = x @ w_key  
values = x @ w_value  
  
print("Querys: \n", querys)  
# tensor([[3., 2., 4., 2.],  
#         [3., 5., 7., 1.],  
#         [5., 5., 8., 3.],  
#         [4., 3., 5., 3.]])  
  
print("Keys: \n", keys)  
# tensor([[5., 8., 2., 3.],  
#         [2., 3., 4., 1.],  
#         [6., 8., 5., 4.],  
#         [5., 5., 4., 4.]])  
print("Values: \n", values)  
# tensor([[ 2.,  5.,  7.,  6.],  
#         [ 1.,  3.,  5.,  5.],  
#         [ 3.,  6., 11.,  8.],  
#         [ 3.,  4., 10.,  5.]])
```

4. 计算attention scores分数

在得到每个输入的q,k和v后，根据公式，下一步需要讲q与k的转置相乘，即做点乘，如将第一个input的query分别与其他的key相乘，得到第一个input与其他input的相似度。

```
attention_scores = querys@keys.T  
print("attention_scores: \n",attention_scores)  
  
# tensor([[ 45.,  30.,  62.,  49.],  
#        [ 72.,  50.,  97.,  72.],  
#        [ 90.,  60., 122.,  94.],  
#        [ 63.,  40.,  85.,  67.]])
```

input1的计算示意图如下：

![]()

同理可以得到其他输入计算的attention scores，再除以根号d\_k，d\_k长度为4，则根号d\_k=2，对其计算后得到相似度分数：

```
attention_scores = attention_scores/2  
print("attention_scores: \n",attention_scores)  
  
#tensor([[22.5000, 15.0000, 31.0000, 24.5000],  
#        [36.0000, 25.0000, 48.5000, 36.0000],  
#        [45.0000, 30.0000, 61.0000, 47.0000],  
#        [31.5000, 20.0000, 42.5000, 33.5000]])
```

![]()

5.  使用softmax对其归一化

```
from torch.nn.functional import softmax  
  
attention_scores_softmax = softmax(attention_scores, dim=-1)  
print("attention_scores_softmax: \n", attention_scores_softmax)  
  
#tensor([[2.0312e-04, 1.1234e-07, 9.9830e-01, 1.5009e-03],  
#        [3.7266e-06, 6.2241e-11, 9.9999e-01, 3.7266e-06],  
#        [1.1254e-07, 3.4425e-14, 1.0000e+00, 8.3153e-07],  
#        [1.6699e-05, 1.6917e-10, 9.9986e-01, 1.2339e-04]])
```

示意图如下：

![]()

从以上的图上可以看到，因为α1,1输出为一个数值，则key和query的维度不需要和value的维度保持一致。

6.  得到outputs 

在得到归一化的数值后，每一个数值相当于一个相似度的权重，与对应输入的value相乘后相加，得到对应的output，这个b1的output的意思是其他a2,a3以及a4的信息量对a1的一个影响。示意图如下：

![]()

同理b2的计算示意图，可以参考下图：

![]()

以上即为self-attention的经过，最后我们就到b1,b2,b3,b4，即为a1,a2,a3,a4的输入输出的features，如同CNN提取到的features,这样每个b都包含了整个的全局信息。

**03****multi-head-self-attention 机制**

在了解了self-attetion机制过后，我们在了解多头注意力机制，具体即为如果将前面的、和做为一个head的话，那multi-head即为多个w\_query、w\_key和w\_value。

![]()

与single-head-self-attention相比，如上图，在三个head分别得到三个b‘1后，先将其首尾concate起来后，再通过一个可学习的权重W得到最后的b1，多头注意力机制能让每个注意力机制通过QKV映射到不同的空间去学习特征，去优化每个词汇的不同特征部分，从而均衡同一种注意力机制可能产生的偏差，让学习到的特征拥有来自更多元的表达，实验表明可以从而提升模型效果。

虽然多头注意力机制的要学习的参数量比single-head的多几倍，但是计算量其实差不多，主要是可以通过并行计算的方式来降低计算量。
