**AUC的实际应用**

AUC(Area Under Curve)一般用于模型评测的评价指标，同时因为作为评价指标，所以有研究者将其直接用于loss中，优化AUC指标。

**01 模型评测**

在模型评测指标中，AUC指标一般用于分类场景，在搜索推荐场景下，也会被用于排序指标的评测。

分类场景

在分类场景中，AUC常用于二分类场景下的模型评测，在二分类中，具体计算方式参见[深入浅出AUC系列一](http://mp.weixin.qq.com/s?__biz=MzU3ODk2Njc5Mg==&mid=2247498491&idx=1&sn=5d59afa4c70b65850a768ba34fefcdbc&chksm=fd6ffe9cca18778a6065586ed1182b0fd624d624e66d99e48443ec669f68550fb2720b933ee4&scene=21#wechat_redirect),这里做一些实际场景的引申：

![]()

原图自网络，侵删

在我们假设已经有一个分类模型并生成AUC曲线后，从图中可以看出AUC曲线从左到右正负样本的置信度从高到低，**由此可得AUC曲线左下角区域正样本的置信度高，为简单的正样本，负样本的置信度高，为困难的负样本；右上角区域正样本的置信度低为困难的正样本，负样本的置信度低，为简单的负样本**；由此，可以通过在对**AUC横纵坐标卡不同的阈值**，筛选出其中的困难正样本和困难负样本，对其做数值分析，有点类似于置信学习，这是一个涨点的trick，亲测是有效的。

如果再做引申的话，可以**在训练的时候动态选取**困难正负样本和简单正负样本，对**loss取不同的权重**，相对于focal loss通过置信度对困难和简单样本取不同权重，这里增加了对困难和简单的正负样本取不同的权重，更细腻度的分析是困难正样本还是困难负样本对模型训练的影响更大。

对于AUC的研究，有学者将其引申到多分类场景中，多分类场景中，AUC一般会有两种计算方式：第一种将多分类简化成多个二分类的场景，生成多个二分类的ROC曲线（**称为宏观AUC, macro**），这里不做赘述，也有直接按多分类来做(**称为微观AUC, micro**)，其混淆矩阵类似于以下： 

![]()

这里有一个计算方法可以参考sklearn中的metrics.roc\_auc\_score函数，即将标签改成0和1,1表示预测正确，0表示预测错误，如果模型对该样本预测分类正确，则该样本在标签矩阵中1对应的位置在概率矩阵P中的值，即为模型预测该分类的概率值。这样则可以将上述的混淆矩阵变成如下:

![]()

如样本一真实类别是A，预测成了B，其概率为P(A,B)，预测成其他类别的为1-P(A,B),这样则将多分类转换成二分类，进行下一步的计算。

推荐场景

在推荐排序场景中，也常用到AUC作为评价指标，这块因为之前没有做过相关的项目，只能了解大概的概念，线上AUC,线下AUC,GAUC之类，怕误导到大家，感兴趣欢迎交流（hhh），推荐关于排序AUC的讲解：[笔记︱统计评估指标AUC 详解](https://mp.weixin.qq.com/s?__biz=MzIzMDcwMDkzOA==&mid=2247485446&idx=1&sn=28a127e4877b3d3dd84d6ab7f060ac4d&scene=21#wechat_redirect)

其他场景

如在目标检测场景下，因为预测出来的结果与真实框做对比，所以一般没有TN(正确的负样本)，这种场景下可对**负样本**做一个**重新定义**：如一个目标检测模型，10张图片有50个真实框，在卡score阈值为0.01(一般情况下，为评测模型，会将score阈值取很小，可以对模型做全阈值的评测)，出来的预测框假如有200个某类别的预测框，在score阈值取最小的0.01时，计算其中的TP,FP,FN值，计算方法参见[map计算方法](http://mp.weixin.qq.com/s?__biz=MzU3ODk2Njc5Mg==&mid=2247494316&idx=1&sn=8f367d235bf5e5a757f05fc2ecede0fc&chksm=fd6feecbca1867dd6677ef5df97c03ed90d0cfdcefc46f3618140a88874ca9f03804ef0514d4&scene=21#wechat_redirect)，得到的FP框数量默认为所有的负样本数量，如有50个。

![]()

而后在ROC曲线时，当score阈值增大时，FN值增大，FP值减小，这里ROC曲线：FPR=FP/(FP+TN)=FP/50，TPR=TP/(TP+FN),则简化成分类任务的ROC曲线计算，进而得到AUC值。

在目标检测任务中获得AUC值的意义在哪里呢，首先目标检测任务中，一般会将多分类任务转换成二分类任务，对于某个类别，**AUC值主要表示该类别与其他类别的区分度**，如果区分度不高，则AUC值低。如在烟火检测任务中，烟相对于背景中云的区分度低，对目标检测中的数据分析有用。

**AUC的python实现**

AUC的python实现有两种方式，一种是自己通过ROC曲线或者排序的方式实现，另外一种方法通过调用sklearn库。

**01 第一种方式**

自己实现AUC的计算也有三种方法，分别对应ROC曲线方法、排序方法以及排序方法的优化。

ROC曲线方法

import numpy as npimport matplotlib.pyplot as plt  
roc_point = []    for i in range(num):        i = pred_prob[i]        TP = 0  # 真阳样本数        FP = 0  # 假阳样本数        TP_rate = 0.  # 真阳率        FP_rate = 0.  # 假阳率        pos_num = 0   # 预测真样本数  
        # 计数过程        for ind, prob in enumerate(pred_prob):            if prob>i:                pos_num += 1            if prob>i and labels[ind]>0.5:                TP+=1            elif prob>i and labels[ind]<0.5:                FP+=1        if pos_num!=0:            TP_rate = TP / sum(labels)            FP_rate = FP / (num-sum(labels))        roc_point.append([FP_rate, TP_rate])  # 记录ROC中的点    # 画出ROC曲线    roc_point.sort(key=lambda x: x[0])    plt.plot(np.array(roc_point)[1:, 0], np.array(roc_point)[1: ,1])    plt.xlabel("FPR")    plt.ylabel("TPR")    plt.show()  
    # 计算每个小长方形的面积，求和即为auc    lastx = 0.    for x,y in roc_point:        auc1 += (x-lastx)*y  # 底乘高        lastx = x  
    print("方法一 auc:", auc1)

   # 方法二，利用AUC关于排列概率的定义计算    auc2 = 0    P_ind = []  # 正样本下标    F_ind = []  # 负样本下标    P_F = 0  # 正样本分数高于负样本的数量    F_P = 0  # 负样本分数高于正样本的数量
