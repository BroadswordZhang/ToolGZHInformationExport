# 高像素图像检测小物体的一种有效工具

**|****导读**

**![]()**

**|****实例**

数据集：DOTA数据集 (v1.0)，包含尺寸从 800x800 到 20.000x20.000 像素的航拍图像，训练数据包含大约 1400 张图像。

![]()

该数据集包含以下 15 个类的边界框注释：

```
classes = [  'soccer-ball-field', 'small-vehicle', 'large-vehicle', 'roundabout', 'tennis-court',  'plane', 'swimming-pool', 'ship', 'harbor', 'ground-track-field',  'baseball-diamond', 'basketball-court', 'storage-tank', 'helicopter', 'bridge'  ]
```

针对此类问题微调预训练检测器，如使用mmdetection 框架，检测小物体通常非常困难，主要有两个原因：

1. 这些模型大多是在中大型检测对象上预训练的（例如在 COCO 数据集上）

2. 通常输入图像被重新缩放到一个相当小的尺寸，例如(640, 640)，这样会丢失很多信息。小物体在图像下采样过程中甚至不再可见，模型没有机会检测到它们。

![]()

所以我们需探索一种在mmdetection 框架上，使用 DOTA 数据集，微调 Faster R-CNN 的方法。为此，须首先重新对标签处理使其符合 COCO 标准，而后从网上下载对应的预训练模型和配置文件。最后，根据需要修改配置，尤其是标签和图像路径以及类别路径。

为了避免在模型的训练预处理pipline中，由于图像大小的调整而丢失小对象，我们在pipline预处理部分添加一个随机裁剪，为了在预测完成后能将对应框和标签返回到原始图片上，在预处理时，需要保存裁剪的所有信息。具体代码参考如下：

```
train_pipeline = [  dict(type='LoadImageFromFile'),  dict(type='LoadAnnotations', with_bbox=True),  dict(type='RandomCrop', crop_size=(height, width)),  dict(  type='Resize',  img_scale=[(1333, 640), (1333, 672), (1333, 704), (1333, 736),  (1333, 768), (1333, 800)],  multiscale_mode='value',  keep_ratio=True),  dict(type='RandomFlip', flip_ratio=0.5),  dict(  type='Normalize',  mean=[103.53, 116.28, 123.675],  std=[1.0, 1.0, 1.0],  to_rgb=False),  dict(type='Pad', size_divisor=32),  dict(type='DefaultFormatBundle'),  dict(type='Collect', keys=['img', 'gt_bboxes', 'gt_labels'])  ]
```

另一种方法是通过预先对所有图像进行从上到下从左到右的以一定窗口的滑窗切片来创建衍生数据集，对衍生数据集做训练。

我们还在配置中添加了一个 tensorboard 日志挂钩，以可视化训练进度。

```
  log_config = dict(  interval=50,  hooks=[  dict(type='TextLoggerHook'),  dict(type='TensorboardLoggerHook')  ])
```

在配置文件中配置好优化器后，通过运行 mmdetection 提供的训练脚本训练数据集，这是我们 10 个 epoch 运行的训练进度：

![]()

![]()

在loss趋于平滑后，模型趋于收敛，我们现在可以使用保存的模型进行推理。

然而，如何对大规模输入图像进行推理是一个令人头疼的问题。在训练时对输入图片先前做过预处理，在输入进模型的图片已经随机裁剪变小。但在推理的时候随机裁剪后的前处理和后处理之间需要链接的数据很多，处理繁杂。这就是**切片辅助推理 (SAHI)** 发挥作用的地方。SAHI 的切片预测将输入图像通过滑窗分解为略微重叠的块，对每个块执行预测，最后合并每个块的注释以在原始图像上可视化它们。

下面的示例代码使用 SAHI 进行推理：

```
  from sahi.model import MmdetDetectionModel  from sahi.predict import get_prediction, get_sliced_prediction, predict  from sahi.utils.cv import visualize_object_predictions    detection_model = MmdetDetectionModel(  model_path=trained_model_path,  config_path=config_path,  device='cuda' # or 'cpu'  )   sliced_pred_result = get_sliced_prediction(  test_img_path,  detection_model,   slice_width=width,   slice_height=height  )    visualize_object_predictions(  image=np.ascontiguousarray(sliced_pred_result.image),  object_prediction_list=sliced_pred_result.object_prediction_list,  rect_th=1,  text_size=0.3,  text_th=1,  color=(0, 0, 0),  output_dir=viz_path,  file_name=test_img_name + "_sliced_pred_result",  export_format=format,  )
```

**|****结语**

经测试，SAHI 目前可与 mmdetection任一模型（如 Cascade R-CNN）接口对接，开箱即用，非常方便。这样不需在图像处理上花费太多精力，将更多的时间用于对于模型本身的优化，这种方法在对高分辨率图像中小物体的高质量检测方面有很大潜力。
